# Goal Programming for Bakery Production Optimization

### Operations Research | Mathematical Optimization | MATLAB

## Project Overview

This project presents a real-world application of goal programming to optimize production planning at Food Art (Pvt) Ltd, a bakery manufacturing company.

The study develops a mathematical optimization model to determine weekly bread and bun production quantities while considering multiple business objectives, including profit targets, production costs, and available packing and baking time.

MATLAB's linear programming solver is used to obtain a production solution.

## Project Objectives

- Apply goal programming to a real-world production planning problem.
- Determine suitable weekly production quantities for bread and buns.
- Meet the company's profit target while controlling production costs.
- Minimize overtime requirements for packing and baking.
- Support production planning through mathematical optimization.

## Methodology

The project follows these main stages:

1. **Data Collection:** Gather production, ingredient cost, operational cost, and working-hour information.
2. **Decision Variables:** Define weekly production quantities for bread and buns.
3. **Goal Formulation:** Establish profit, cost, packing-time, and baking-time goals.
4. **Mathematical Modeling:** Formulate goal constraints with positive and negative deviation variables.
5. **Optimization:** Solve the formulated linear programming model using MATLAB.
6. **Result Interpretation:** Evaluate the resulting production quantities and operational recommendations.

## Production Planning Goals

| Priority | Goal |
|---|---|
| P1 | Achieve a weekly profit of at least Rs. 1,400,000 |
| P2 | Keep weekly costs below Rs. 1,900,000 |
| P3 | Avoid overtime for packing |
| P4 | Avoid overtime for baking |

## Results

The reported MATLAB optimization solution suggested:

- **Weekly bread production:** Approximately 0 units
- **Weekly bun production:** Approximately 113,235 units
- **Daily bun production:** Approximately 16,176 units

These are the reported results of the case study's mathematical model, rather than independently validated operational recommendations.
